# VolFix Global · Pro — лендинг для практикующих трейдеров

Второй лендинг того же продукта, но под другую аудиторию и в другом визуальном языке.

| | Базовый лендинг | Этот (Pro) |
|---|---|---|
| Аудитория | новички, вход с нуля | те, кто уже торгует |
| Обещание | пошаговый план входа в рынок | данные под движением: объём, дельта, поток ордеров |
| Тон | на «ты», объясняющий | на «вы», без разжёвывания |
| Дизайн | тёмно-синий #0B1B2B, зелёный акцент | светлая тема Apple: SF-типографика, синий #0071e3, чёрная секция под визуал |
| Квиз перед оплатой | включён | выключен — опытной аудитории лишний шаг мешает |
| Ключевой визуал | свечи и объёмы фоном | футпринт bid × ask как продуктовый шот |

Секции: hero с продуктовым визуалом → строка характеристик → платформа (чёрная секция) →
группа → кому подойдёт / кому нет → автор → цена → FAQ → финальный CTA → риски.

Блок «Кому не подойдёт» ведёт новичков на базовый лендинг — ссылка в `config.js` (`links.basic`).

## Стек

Статика: HTML + CSS + vanilla JS. Без сборки, npm и внешних библиотек.
Движок i18n, форма лида, аналитика и заглушки оплаты — те же, что в базовом проекте.

```bash
python3 -m http.server 4322   # http://localhost:4322
```

### Кэш при обновлениях

Ассеты подключены с версией (`styles.css?v=1`). **После каждого деплоя поднимайте номер**
в `index.html` и `success.html`, иначе браузеры отдадут старые скрипты поверх нового HTML.

## Что настраивается в `assets/js/config.js`

| Поле | Что делает |
|---|---|
| `price.*` | цена, валюта, период; подставляется во все блоки |
| `volfixBonusWeeks` | «2 недели» во всех текстах обоих языков |
| `payment.provider / payUrl` | `stub` — демо; иначе редирект на платёжку |
| `leads.endpoint` | куда POST-ить лид; пусто — localStorage + консоль |
| `quizEnabled` | здесь `false`; `true` вернёт квиз перед формой |
| `seats.left / total` | честный счётчик мест; `seats: null` скроет |
| `links.basic` | ссылка на базовый поток для новичков |
| `analytics.*` | ID пикселей; пустой ID = скрипт не грузится |

## Языки

RU и KZ, 136 зеркальных ключей. Приоритет: `?lang=kk` → выбор пользователя → браузер → RU.
Казахский — смысловой перевод; терминология (футпринт, дельта, кластер, стакан) оставлена
в общепринятом виде. Перед проливом трафика стоит вычитать носителем.

## Заглушки

Оплата и выдача Telegram-ссылки — демо-режим, как в базовом проекте.
Реальный сценарий (вебхук → `createChatInviteLink` с `member_limit: 1` → показ и дубль
на почту/SMS) описан в `api/payment-webhook.js` базового репозитория.

- Реальное число мест в потоке (сейчас 8 из 30).
- Фото Ерлана вместо плейсхолдера.
- Ссылки на оферту и политику конфиденциальности.
